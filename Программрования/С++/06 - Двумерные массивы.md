# Двумерные массивы

## Представление
Двумерный встроенный массив можно рассматривать как таблицу строк и столбцов.

```cpp
int grid[3][4]{};
```

Индекс первого измерения выбирает строку, второго — столбец: `grid[row][column]`.

## Обход
```cpp
for (int row = 0; row < rows; ++row) {
    for (int column = 0; column < columns; ++column) {
        // grid[row][column]
    }
}
```

## Типичные задачи
- сумма строки или столбца;
- поиск минимума/максимума;
- подсчёт ячеек по условию;
- поиск элемента;
- главная и побочная диагонали квадратной матрицы;
- транспонирование;
- проверка свойств матрицы;
- табличный учёт запасов или результатов.

## Передача в функцию
У встроенного двумерного массива тип включает размер последующих измерений. В обычной функции нужно указать число столбцов:
```cpp
void printMatrix(const int matrix[][4], int rows);
```
Для более гибких размеров в дальнейшем изучают контейнеры и другие представления данных.

## Частые ошибки
- перепутанные строки и столбцы;
- неверные границы вложенных циклов;
- обращение к диагонали у неквадратной матрицы без проверки;
- предположение, что обычный двумерный массив — то же самое, что `int**`;
- выход за границы при транспонировании или обходе соседних ячеек.
