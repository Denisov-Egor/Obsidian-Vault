# Функции

## Назначение
Функция объединяет операцию под именем, уменьшает дублирование и позволяет проверять части программы отдельно.

```cpp
int sum(int a, int b) {
    return a + b;
}
```

## Объявление и определение
Объявление сообщает компилятору сигнатуру. Определение содержит тело функции. Объявление можно поместить выше места использования или в заголовочный файл.

## Параметры
- **По значению:** функция получает копию.
- **По ссылке:** `T&` позволяет работать с исходным объектом и изменять его.
- **По константной ссылке:** `const T&` позволяет читать объект без копирования.
- **Указатель:** `T*` передаёт адрес; указатель может быть `nullptr`.

## Возвращаемое значение
Тип результата указывается перед именем. `void` означает, что функция не возвращает значение. Не допускай, чтобы функция с возвращаемым типом завершалась без подходящего `return`.

## Область видимости
Локальная переменная доступна только внутри своей области видимости. После выхода из неё время жизни обычной локальной переменной заканчивается.

## Хорошая функция
- выполняет одну понятную операцию;
- имеет осмысленное имя;
- явно принимает необходимые данные;
- возвращает результат вместо неявного изменения глобального состояния;
- проверяет важные предусловия.

## Типичные ошибки
- слишком длинная функция с несколькими несвязанными обязанностями;
- ненужное копирование больших объектов;
- изменение аргумента, хотя ожидалось только чтение;
- возврат ссылки/указателя на локальную переменную;
- глобальные переменные как способ связать все части программы.
