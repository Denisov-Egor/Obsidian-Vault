# Roadmap — Rust

## Цель
Научиться самостоятельно писать надёжные программы на Rust, понимать ownership и borrowing, работать с ошибками, файлами, процессами, потоками и системными интерфейсами.

## Правила обучения
- [ ] Не копировать готовые решения: сначала спроектировать, затем реализовать.
- [ ] Закреплять темы практикой на текущих и ранее изученных концепциях.
- [ ] Переходить дальше, когда можешь объяснить ключевую идею и написать небольшой пример самостоятельно.
- [ ] Использовать актуальную документацию установленной версии Rust.
- [ ] Не считать прочитанную теорию освоенной без написанного кода.

## Текущее состояние
- [ ] Rust ещё не начат.
- [ ] C++ остаётся отдельным треком; этот план посвящён только Rust.
