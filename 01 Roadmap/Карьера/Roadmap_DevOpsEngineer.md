# Systems Engineer — Roadmap

## Цель

Научиться разрабатывать системное программное обеспечение: работать с памятью, процессами, файловыми системами, сетями, многопоточностью и производительностью.

Основной язык — C++. Rust и Zig изучаются отдельно после формирования прочной базы.

## Этап 1. Современный C++

- [ ] Классы и объекты
- [ ] Инкапсуляция и инварианты
- [ ] Конструкторы и деструкторы
- [ ] RAII и управление ресурсами
- [ ] Copy и move semantics
- [ ] Умные указатели
- [ ] STL: контейнеры и алгоритмы
- [ ] `const`, ссылки и время жизни объектов
- [ ] Шаблоны
- [ ] Обработка ошибок
- [ ] Разделение интерфейса и реализации
- [ ] CMake и организация проекта

Практика:
- [ ] Переработать систему управления заказами в классы с чёткими обязанностями
- [ ] Написать библиотеку разбора конфигурации
- [ ] Покрыть бизнес-логику тестами

Критерий завершения: понимаю владение ресурсами, могу объяснить дизайн классов и самостоятельно отладить ошибки памяти.

## Этап 2. Linux и системное программирование

- [ ] Файловая система и права доступа
- [ ] Процессы и потоки
- [ ] Файловые дескрипторы
- [ ] Системные вызовы
- [ ] `open`, `read`, `write`, `close`, `stat`
- [ ] `fork`, `exec`, `wait`
- [ ] Сигналы и коды завершения
- [ ] Переменные окружения
- [ ] Стандартные потоки и перенаправление
- [ ] `/proc` и диагностика процессов
- [ ] Обработка частичных операций и `errno`

Практика:
- [ ] Создать CLI-утилиту для анализа файлов
- [ ] Реализовать запуск внешней команды и обработку её завершения
- [ ] Написать инструмент анализа процессов Linux

Критерий завершения: понимаю разницу между библиотечными функциями и системными вызовами, умею диагностировать ошибки файловых операций.

## Этап 3. Память и производительность

- [ ] Стек, куча и статическое хранение
- [ ] Виртуальная память
- [ ] Адресное пространство процесса
- [ ] Выравнивание и padding структур
- [ ] Неопределённое поведение
- [ ] Use-after-free и memory leaks
- [ ] AddressSanitizer и UndefinedBehaviorSanitizer
- [ ] Valgrind
- [ ] Кэш процессора и locality
- [ ] Профилирование CPU и памяти

Практика:
- [ ] Найти и исправить несколько ошибок управления памятью
- [ ] Сравнить две реализации обработки больших наборов данных
- [ ] Измерить время и потребление памяти до и после оптимизации

Критерий завершения: могу обнаружить проблему, воспроизвести её и подтвердить исправление инструментами.

## Этап 4. Сети

- [ ] IPv4 и IPv6
- [ ] TCP и UDP
- [ ] Порты и сокеты
- [ ] DNS
- [ ] Блокирующий ввод-вывод
- [ ] Клиент-серверная модель
- [ ] Протоколы приложений
- [ ] Тайм-ауты
- [ ] Частичные чтения и записи
- [ ] Разрыв соединения и сетевые ошибки

Практика:
- [ ] Написать TCP-клиент
- [ ] Создать TCP-сервер с простым текстовым протоколом
- [ ] Добавить тайм-ауты и обработку отключения клиентов

Критерий завершения: сервер корректно работает при ошибочных сообщениях, сетевых сбоях и повторных подключениях.

## Этап 5. Многопоточность

- [ ] `std::thread` и `std::jthread`
- [ ] Гонки данных
- [ ] `mutex`, `lock_guard`, `unique_lock`
- [ ] Атомарные операции
- [ ] Условные переменные
- [ ] Producer-consumer
- [ ] Deadlock и starvation
- [ ] ThreadSanitizer
- [ ] Пулы потоков

Практика:
- [ ] Реализовать потокобезопасную очередь задач
- [ ] Создать несколько рабочих потоков
- [ ] Продумать остановку и обработку ошибок

Критерий завершения: могу объяснить, какие данные разделяются потоками и почему синхронизация корректна.

- [ ] Разделение ответственности

- [ ] Конфигурация
- [ ] Метрики и диагностика
- [ ] Профилирование
- [ ] Управление зависимостями
- [ ] Совместимость форматов данных
- [ ] Версионирование

Практика:
- [ ] Выбрать узкое место в одном из предыдущих проектов
- [ ] Провести измерения
- [ ] Реализовать улучшение
- [ ] Описать компромиссы

- [ ] CMake: библиотеки, тесты и конфигурации
- [ ] CTest

- [ ] CI для сборки и тестов
- [ ] Версионирование релизов
- [ ] Установка программы
- [ ] Воспроизводимая сборка
- [ ] Документация проекта

Начинать после уверенного владения базовыми концепциями C++.

- [ ] Ownership
- [ ] Borrowing
- [ ] Lifetimes
- [ ] `Result` и `Option`
- [ ] Traits
- [ ] Коллекции и итераторы
- [ ] Работа с файлами
- [ ] Потоки и синхронизация
- [ ] Сетевое программирование
- [ ] Cargo и тестирование

Практика:
- [ ] Создать системную CLI-утилиту
- [ ] Сравнить модель владения Rust и C++

Изучать отдельным направлением после знакомства с C-подобной моделью системного программирования.

- [ ] Синтаксис и типы
- [ ] Работа с ошибками
- [ ] Allocator-подход
- [ ] Управление памятью
- [ ] Указатели и срезы
- [ ] `comptime`
- [ ] Модули и сборка
- [ ] C interoperability
- [ ] Тестирование
- [ ] Написание CLI-утилит

Практика:
- [ ] Реализовать небольшую системную утилиту
- [ ] Сравнить сборку и модель памяти с C++

- [ ] Есть 2–3 законченных проекта

- [ ] Понимаю процессы, потоки и системные вызовы
- [ ] Умею отлаживать приложения Linux
- [ ] Пишу тесты
- [ ] Могу объяснить архитектуру своих проектов
- [ ] Умею аргументировать технические решения
