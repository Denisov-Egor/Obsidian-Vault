# Условия и циклы

## Условия

```cpp
if (score >= 90) {
    // ...
} else if (score >= 60) {
    // ...
} else {
    // ...
}
```

`if` выполняет ветвь, когда условие истинно. `else if` проверяет альтернативные условия по порядку; `else` выполняется, если предыдущие условия не сработали.

### `switch`
Используй для выбора между дискретными значениями, например командами меню или значениями `enum`.
```cpp
switch (command) {
case 1:
    // ...
    break;
case 2:
    // ...
    break;
default:
    // неизвестная команда
    break;
}
```
`break` предотвращает переход к следующей метке `case`.

## Циклы
- `for` — когда удобно управлять счётчиком.
- `while` — пока условие истинно.
- `do ... while` — тело выполняется хотя бы один раз.
- `break` — немедленно завершает ближайший цикл.
- `continue` — переходит к следующей итерации.

```cpp
for (int i = 0; i < 5; ++i) {
    // i: 0, 1, 2, 3, 4
}
```

## Типичные ошибки
- ошибка на единицу в условии цикла;
- бесконечный цикл из-за отсутствия изменения состояния;
- использование `=` вместо `==` в сравнении;
- забытый `break` в `switch`;
- слишком сложные условия, которые лучше разбить на именованные функции или промежуточные переменные.
