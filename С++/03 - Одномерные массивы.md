# Одномерные массивы

## Что такое массив
Массив хранит последовательность элементов одного типа. У обычного встроенного массива размер фиксирован.

```cpp
int scores[5]{};
```

Индексы начинаются с `0`. Для массива из `n` элементов допустимы индексы `0 ... n - 1`.

## Обход
```cpp
for (int i = 0; i < 5; ++i) {
    // scores[i]
}
```

## Типичные задачи
- сумма и среднее;
- минимум и максимум;
- поиск значения;
- подсчёт элементов по условию;
- разворот массива;
- сдвиг элементов;
- проверка отсортированности;
- объединение результатов нескольких проходов.

## Передача массива в функцию
При передаче встроенного массива в функцию он обычно преобразуется в указатель на первый элемент, поэтому размер нужно передавать отдельно.

```cpp
int sum(const int values[], int size);
```

`const` запрещает функции изменять элементы через этот параметр.

## Частые ошибки
- обращение за границы массива;
- неправильная начальная/конечная граница цикла;
- попытка узнать размер массива через указатель;
- выход за границы при сдвиге или развороте;
- отсутствие проверки размера перед обращением к элементам.
