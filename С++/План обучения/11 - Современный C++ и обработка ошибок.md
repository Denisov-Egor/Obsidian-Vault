# Этап 11 — Современный C++ и обработка ошибок

## Теория
- `auto`, `constexpr`;
- `std::optional`;
- `std::variant`;
- структурированные привязки;
- `std::string_view` и время жизни;
- исключения `try`, `throw`, `catch`;
- гарантии исключений;
- различие ожидаемого отсутствия значения и ошибки.

## Практика
- функция поиска с возможным отсутствием результата;
- разбор нескольких вариантов команды;
- безопасная обработка ошибок чтения;
- найти висячий `string_view`;
- не допускать частично изменённого состояния при ошибке.

## Критерии
- выбирать тип результата по смыслу;
- проверять `optional`;
- обрабатывать все альтернативы `variant`;
- не скрывать ошибки пустым `catch`;
- применять RAII при исключениях.
