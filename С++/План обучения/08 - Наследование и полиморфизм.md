# Этап 8 — Наследование и полиморфизм

## Теория
- базовые и производные классы;
- `virtual`, `override`;
- чисто виртуальные методы;
- абстрактный класс;
- виртуальный деструктор;
- динамический полиморфизм;
- срезка объекта;
- композиция против наследования.

## Практика
- определить общий интерфейс для нескольких реализаций;
- реализовать две производные реализации;
- проверить вызов метода через базовую ссылку/указатель;
- объяснить, почему полиморфный базовый класс требует корректного деструктора.

## Критерии
- применять наследование только при корректном отношении «является»;
- использовать `override`;
- понимать динамический вызов виртуального метода;
- не удалять производный объект через базовый указатель с невиртуальным деструктором.
