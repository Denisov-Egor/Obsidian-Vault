# Указатели

## Основы
Указатель хранит адрес объекта или функции. Указатель на объект может быть нулевым.

```cpp
int value{42};
int* ptr = &value;
```

- `&value` — получить адрес;
- `*ptr` — разыменовать указатель;
- `nullptr` — указатель не указывает на объект.

```cpp
if (ptr != nullptr) {
    std::cout << *ptr;
}
```

## Изменение объекта
Если указатель указывает на доступный для изменения объект, запись через `*ptr` изменяет сам объект.

## `const` и указатели
- `const int* p` — нельзя менять `int` через `p`;
- `int* const p` — сам указатель нельзя переназначить;
- `const int* const p` — нельзя менять ни указатель, ни объект через него.

## Указатели и массивы
В большинстве выражений имя встроенного массива преобразуется в указатель на первый элемент. Указательная арифметика допустима в пределах одного массива и на позицию сразу после последнего элемента, но разыменовывать позицию после последнего нельзя.

## Опасности
- `nullptr` разыменован;
- указатель не инициализирован;
- висячий указатель после завершения времени жизни объекта;
- выход за пределы массива;
- использование адреса после освобождения памяти;
- путаница между адресом и значением по адресу.

## Владение
Сырой указатель сам по себе не сообщает, владеет ли он объектом. Нужно явно понимать, кто отвечает за время жизни. В современном C++ для владения обычно используют контейнеры и умные указатели, а сырые указатели оставляют для невладеющего доступа, когда это уместно.
