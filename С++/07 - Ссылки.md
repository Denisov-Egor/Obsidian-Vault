# Ссылки

## Что такое ссылка
Ссылка — другое имя уже существующего объекта. Ссылка должна быть инициализирована при объявлении и не может быть переназначена на другой объект.

```cpp
int value{10};
int& ref = value;
ref = 20; // value теперь равен 20
```

## Ссылка на константу
```cpp
const int& ref = value;
```
Через такую ссылку нельзя менять объект. Константная ссылка может привязываться к временному значению, продлевая его время жизни в некоторых контекстах; не переносить это правило на возвращаемые ссылки и более сложные случаи без проверки.

## Ссылки в функциях
- `T&` — позволяет менять исходный объект;
- `const T&` — позволяет читать объект без копирования;
- передача по значению — отдельная копия.

```cpp
void increment(int& value) {
    ++value;
}
```

## Когда использовать
- `const T&` для чтения больших объектов без копирования;
- `T&` для функции, которая должна изменить переданный объект;
- обычное значение для небольших типов или когда нужна независимая копия.

## Ограничения и ошибки
- ссылку нельзя оставить неинициализированной;
- ссылка не является самостоятельным объектом-владельцем;
- нельзя возвращать ссылку на локальную переменную;
- не путай `const T&` с полной неизменяемостью объекта через другие доступы;
- не используй неконстантную ссылку, если функция не должна изменять аргумент.
