# Git — команды

Git — распределённая система контроля версий, позволяющая отслеживать изменения файлов, управлять историей проекта и работать совместно с другими разработчиками.

## 1. Основные понятия

|Понятие|Описание|
|---|---|
|Working Directory|Рабочая директория, где находятся файлы проекта|
|Staging Area|Область подготовки изменений к коммиту|
|Repository|Хранилище истории изменений|
|Commit|Зафиксированное состояние проекта|
|Branch|Отдельная ветка разработки|
|Remote|Удалённый репозиторий|

### Жизненный цикл изменений

```
Working Directory
       |
       | git add
       v
Staging Area
       |
       | git commit
       v
Local Repository
       |
       | git push
       v
Remote Repository
```

## 2. Основные команды

|Команда|Назначение|
|---|---|
|`git --version`|Версия Git|
|`git help`|Справка|
|`git status`|Состояние репозитория|
|`git init`|Создать репозиторий|
|`git clone <url>`|Клонировать репозиторий|
|`git config --list`|Посмотреть настройки|
|`git log`|История коммитов|

## 3. Работа с изменениями

|Команда|Назначение|
|---|---|
|`git status`|Проверить изменения|
|`git add <file>`|Добавить файл в Staging Area|
|`git add .`|Добавить изменения текущей директории|
|`git add -A`|Добавить все изменения репозитория|
|`git diff`|Показать незастейдженные изменения|
|`git diff --staged`|Показать подготовленные изменения|
|`git restore <file>`|Отменить изменения файла|
|`git restore --staged <file>`|Убрать файл из Staging Area|

## 4. Коммиты

Коммит фиксирует подготовленные изменения в истории репозитория.

|Команда|Назначение|
|---|---|
|`git commit -m "message"`|Создать коммит|
|`git commit -am "message"`|Добавить изменения отслеживаемых файлов и создать коммит|
|`git commit --amend`|Изменить последний коммит|
|`git show`|Показать последний коммит|
|`git log --oneline`|Краткая история коммитов|
|`git log --oneline --graph --all`|Граф истории всех веток|

## 5. Удалённые репозитории

|Команда|Назначение|
|---|---|
|`git remote -v`|Показать удалённые репозитории|
|`git remote add origin <url>`|Добавить удалённый репозиторий|
|`git remote remove origin`|Удалить удалённый репозиторий|
|`git fetch`|Получить изменения с сервера|
|`git pull`|Получить и объединить изменения|
|`git push`|Отправить коммиты|
|`git push -u origin main`|Отправить ветку и настроить upstream|
|`git push --force-with-lease`|Принудительно обновить удалённую ветку с проверкой|

## 6. Работа с ветками

Ветки позволяют разрабатывать новые функции независимо от основной версии проекта.

|Команда|Назначение|
|---|---|
|`git branch`|Показать локальные ветки|
|`git branch -a`|Показать все ветки|
|`git branch <name>`|Создать ветку|
|`git switch <name>`|Переключиться на ветку|
|`git switch -c <name>`|Создать и переключиться|
|`git branch -d <name>`|Удалить ветку|
|`git merge <name>`|Объединить ветку с текущей|
|`git rebase <name>`|Перенести коммиты на другую основу|

## 7. Отмена изменений

|Команда|Назначение|
|---|---|
|`git restore <file>`|Отменить изменения файла|
|`git reset <file>`|Убрать файл из Staging Area|
|`git reset --soft HEAD~1`|Отменить последний коммит, сохранив Staging Area|
|`git reset --mixed HEAD~1`|Отменить коммит, сохранив изменения в файлах|
|`git reset --hard HEAD~1`|Отменить коммит и удалить соответствующие изменения|
|`git revert <commit>`|Создать коммит, отменяющий другой коммит|
|`git reflog`|Посмотреть историю перемещения HEAD|

> **Внимание:** `git reset --hard` может безвозвратно удалить незакоммиченные изменения.

## 8. Просмотр истории и поиск

|Команда|Назначение|
|---|---|
|`git log`|Полная история|
|`git log -5`|Последние 5 коммитов|
|`git log --oneline`|Краткая история|
|`git show <commit>`|Информация о коммите|
|`git blame <file>`|Авторство изменений каждой строки|
|`git diff HEAD~1`|Сравнить состояние с предыдущим коммитом|
|`git grep "text"`|Поиск текста в отслеживаемых файлах|

## 9. Дополнительные команды

|Команда|Назначение|
|---|---|
|`git clean -n`|Показать неотслеживаемые файлы для удаления|
|`git clean -f`|Удалить неотслеживаемые файлы|
|`git stash`|Временно сохранить изменения|
|`git stash list`|Показать сохранённые изменения|
|`git stash pop`|Вернуть сохранённые изменения|
|`git tag`|Показать теги|
|`git tag <name>`|Создать тег|
|`git rm <file>`|Удалить файл из Git и рабочей директории|
|`git mv <old> <new>`|Переместить или переименовать файл|

## 10. Типичный рабочий процесс

Пример работы над C++ проектом:

```
# Проверить состояние проекта
git status

# Посмотреть изменения
git diff

# Добавить изменения
git add .

# Проверить подготовленные файлы
git status

# Создать коммит
git commit -m "Add inventory management"

# Отправить изменения на GitHub
git push
```

## 11. Полезные настройки

### Информация пользователя

```
# Установить имя
git config --global user.name "Your Name"

# Установить email
git config --global user.email "your@email.com"

# Посмотреть настройки
git config --list
```

### Редактор и отображение

```
# Установить Neovim редактором Git
git config --global core.editor "nvim"

# Использовать цветной вывод
git config --global color.ui auto

# Использовать less для просмотра длинного вывода
git config --global core.pager less
```

### Отключение постраничного просмотра

Если Git открывает `less` при просмотре истории или diff:

```
# Для одной команды
git --no-pager log

# Отключить pager глобально
git config --global core.pager cat
```

Чтобы выйти из `less`, нажми `q`.
