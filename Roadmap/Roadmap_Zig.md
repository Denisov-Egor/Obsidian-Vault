# Roadmap — Zig

## Цель
Научиться самостоятельно создавать системные программы на Zig, понимать явное управление памятью, систему типов, обработку ошибок, компиляцию, взаимодействие с C и системными API.

## Правила обучения
- [ ] Сначала понять задачу и спроектировать решение, затем писать код.
- [ ] Закреплять темы практикой на текущих и предыдущих концепциях.
- [ ] Переходить дальше, когда можешь объяснить ключевую идею и написать небольшой пример.
- [ ] Использовать документацию для установленной версии Zig.
- [ ] Проверять примеры из старых учебников: Zig быстро развивается, API и синтаксис могут меняться.
- [ ] Не считать теорию освоенной без самостоятельного кода.

## Текущее состояние
- [ ] Zig ещё не начат.
- [ ] Этот файл посвящён только Zig; C++ и Rust имеют отдельные планы.
