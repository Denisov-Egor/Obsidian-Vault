# Строки

## `std::string`
`std::string` — стандартный тип для хранения и изменения текста. Подключается через `<string>`.

```cpp
#include <string>

std::string name{"Fastik"};
```

## Частые операции
- `size()` / `length()` — количество элементов строки;
- `empty()` — пустая ли строка;
- `operator[]` — доступ к символу без проверки границы;
- `at(i)` — доступ с проверкой границы;
- `+=` и `append()` — добавление;
- `find()` — поиск подстроки или символа;
- `substr(pos, count)` — получение подстроки;
- `clear()` — очистка;
- `std::getline(std::cin, text)` — чтение строки с пробелами.

## Ввод с `cin` и `getline`
`std::cin >> text` обычно читает только до пробельного символа. `std::getline` читает всю строку до перевода строки.

Если после `operator>>` вызывается `getline`, во входном потоке может остаться `\\n`. В таком случае нужно корректно убрать остаток строки, например через `std::cin.ignore(...)` с подходящими параметрами.

## Обход строки
```cpp
for (char ch : text) {
    // обработка ch
}
```

## Важное ограничение
`std::string` хранит байты. Индекс обычно означает позицию байта, а не пользовательского символа Unicode. Кириллический символ в UTF-8 может занимать несколько байтов.

## Типичные задачи
- подсчёт символов;
- изменение регистра латинских букв;
- проверка палиндрома;
- поиск подстроки;
- разбиение строки на слова;
- удаление лишних пробелов;
- проверка формата ввода.

## Типичные ошибки
- выход за границы;
- путаница между байтами и Unicode-символами;
- использование `getline` после форматированного ввода без обработки остатка строки;
- ненужное изменение исходной строки при проверке;
- предположение, что `find()` возвращает `0`, если значение не найдено: результат отсутствия — `std::string::npos`.
