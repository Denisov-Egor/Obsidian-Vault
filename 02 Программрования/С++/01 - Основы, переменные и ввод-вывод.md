# Основы, переменные и ввод-вывод

## Переменная и тип
Переменная — именованное хранилище значения. Тип определяет диапазон значений, операции и способ представления.

Основные типы:
- `bool` — `true` или `false`;
- `char` — символ/небольшое целое;
- `int` — целое число;
- `long long` — целое число увеличенного диапазона;
- `float`, `double` — числа с плавающей точкой;
- `std::string` — строка текста.

## Инициализация
```cpp
int count{0};
double price{19.99};
bool isReady{false};
```
Инициализируй переменные при объявлении. Не используй неинициализированное локальное значение.

## Ввод и вывод
```cpp
#include <iostream>

int main() {
    int age{};
    std::cout << "Age: ";
    std::cin >> age;
    std::cout << "Entered: " << age << '\\n';
}
```
- `std::cout` выводит данные.
- `std::cin` читает форматированные данные.
- `std::cerr` предназначен для сообщений об ошибках.
- `\\n` переводит строку; `std::endl` дополнительно сбрасывает буфер, поэтому не нужен для каждой строки.

## Операторы
- Арифметические: `+`, `-`, `*`, `/`, `%`.
- Сравнения: `==`, `!=`, `<`, `>`, `<=`, `>=`.
- Логические: `&&`, `||`, `!`.
- Присваивание: `=`, `+=`, `-=`, `*=`, `/=`.

Целочисленное деление отбрасывает дробную часть: `7 / 2 == 3`.

## Преобразования и ввод
Не смешивай типы без понимания преобразования. Проверяй, удалось ли чтение, особенно если пользователь может ввести текст вместо числа.
