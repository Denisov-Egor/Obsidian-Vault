# Этап 15 — Git, Linux и инструменты разработки

## Git
- `status`, `diff`, `add`, `commit`, `log`;
- ветки, `switch`, `merge`;
- `pull --rebase`;
- разрешение конфликтов;
- `.gitignore`;
- понятные атомарные коммиты.

## Linux
- файловая система и права;
- процессы и коды завершения;
- переменные окружения;
- стандартные потоки;
- перенаправления и конвейеры;
- аргументы командной строки;
- сигналы;
- компилятор, линкер, библиотеки.

## Инструменты
- `g++` или `clang++`;
- `cmake`;
- `gdb`;
- `clang-format`;
- `git`;
- AddressSanitizer и UndefinedBehaviorSanitizer.

## Практика
- собрать проект вручную и через CMake;
- включить предупреждения компилятора;
- изучить код завершения процесса;
- написать скрипт сборки/проверки;
- поддерживать чистую историю Git.
