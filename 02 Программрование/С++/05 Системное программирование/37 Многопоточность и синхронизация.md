## Теория
- Потоки разделяют память. Data race — конфликтующие несинхронизированные обращения, одно из которых запись
- в C++ это UB. `mutex`, `lock_guard`, `unique_lock`, `condition_variable`, `atomic`. Условную переменную использовать с предикатом. Deadlock снижать единым порядком блокировок. Memory ordering требует понимания модели.

## Типичные ошибки
- Гонка общей переменной
- забытый join
- ожидание без предиката
- разный порядок mutex
- сложный memory ordering без причины.
