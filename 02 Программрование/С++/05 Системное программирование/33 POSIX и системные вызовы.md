# 33 POSIX и системные вызовы

## Цели
- [ ] Понимать взаимодействие программы и ОС.
- [ ] Обрабатывать отказ и недоверенные данные.

## Теория
- Системный вызов просит услугу ядра
- библиотечная функция может быть обёрткой. POSIX API часто сигнализирует ошибку возвращаемым значением и `errno`
- errno проверяют после признака ошибки. Дескриптор обозначает открытый ресурс. RAII-обёртка автоматически закрывает дескриптор.

## Типичные ошибки
- Игнорировать частичное чтение/запись
- проверять errno после успеха
- не закрывать дескриптор
- считать вызов полностью обработавшим буфер.
