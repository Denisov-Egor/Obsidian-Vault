# 38 Профилирование и оптимизация

## Цели
- [ ] Понимать взаимодействие программы и ОС.

## Теория
- Профиль распределяет время по функциям
- benchmark измеряет одинаковую нагрузку воспроизводимо. Различать latency и throughput. Измерять базу, менять один фактор, повторять тест. Сравнивать релевантные Release-сборки.

## Типичные ошибки
- Сравнивать один запуск
- оптимизировать без профиля
- измерять Debug как финальную скорость
- игнорировать погрешность.
