# 04 Функции

## Цели
- [ ] Декомпозировать задачу на функции.
- [ ] Определять ясные контракты параметров и результата.

## Теория
- Объявление сообщает сигнатуру, определение содержит тело. Передача по значению копирует аргумент
- ссылка даёт доступ к исходному объекту
- `const T&` позволяет читать без копирования. `return` возвращает значение, `void` — отсутствие значения. Область видимости ограничивает доступ к локальным переменным. Перегрузка различает наборы параметров.

## Типичные ошибки
- Функция делает слишком много
- возврат ссылки на локальный объект
- скрытое глобальное состояние
- дублирование логики.
