# 07 Структуры и перечисления

## Цели
- [ ] Моделировать предметную область типами.
- [ ] Поддерживать инварианты данных.

## Теория
- `struct` объединяет поля разных типов, доступ по умолчанию `public`. `enum` задаёт именованные целочисленные значения. `enum class` ограничивает область имён и обеспечивает строгую типизацию. Агрегатная инициализация подходит простым структурам. Инвариант — условие корректности объекта, например количество неотрицательно.

## Типичные ошибки
- Статус в произвольной строке
- магические числа
- неинициализированные поля
- смешение разных сущностей.

## Практика
- [ ] Заказ с ID, суммой в копейках и статусом
- [ ] товар с ценой и количеством
- [ ] вывод enum через `switch`.
