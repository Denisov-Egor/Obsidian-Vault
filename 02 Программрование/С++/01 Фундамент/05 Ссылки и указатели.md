# 05 Ссылки и указатели

## Цели
- [ ] Понимать адреса, время жизни и владение.
- [ ] Не допускать неопределённого поведения.

## Теория
- `&x` получает адрес
- `T*` хранит адрес
- `*ptr` разыменовывает
- `nullptr` обозначает пустой указатель. `T&` — псевдоним существующего объекта, должен быть инициализирован. `const T&` читает без копирования. Указатели и ссылки не продлевают время жизни объекта.

## Типичные ошибки
- Разыменование `nullptr`
- use-after-free
- возврат ссылки на локальную переменную
- путаница адреса и значения.

## Практика
- [ ] Обмен значений через ссылки
- [ ] обход массива указателем в пределах границ
- [ ] передача крупных объектов без копии.
