# `std::filesystem` и работа с путями

Заголовок: `<filesystem>`, пространство имён: `std::filesystem`, стандартная поддержка — C++17.

## Основные типы и операции

- `std::filesystem::path` — путь без необходимости вручную склеивать строки.
- `exists(path)` — существует ли путь.
- `is_regular_file(path)`, `is_directory(path)` — тип объекта.
- `file_size(path)` — размер обычного файла.
- `create_directories(path)` — создать каталог вместе с родительскими.
- `directory_iterator` — обход одного каталога.
- `recursive_directory_iterator` — рекурсивный обход дерева.
- `extension()`, `filename()`, `parent_path()`, `stem()` — компоненты пути.

```cpp
#include <filesystem>
#include <iostream>

namespace fs = std::filesystem;

int main() {
    const fs::path directory{"."};

    for (const auto& entry : fs::directory_iterator(directory)) {
        std::cout << entry.path().filename().string() << '\n';
    }
}
```

## Обработка ошибок

Многие операции могут бросать `std::filesystem::filesystem_error`. В перегрузках доступен `std::error_code`, если нужен явный контроль без исключения.

- Проверяй, что операция применима к типу объекта.
- Каталог может измениться между проверкой и использованием.
- Ошибка доступа не означает, что путь не существует.
- Не предполагай, что имена файлов имеют одну кодировку или формат на всех платформах.

## Безопасность

- Не считай путь от пользователя доверенным.
- Нормализация пути сама по себе не гарантирует защиту от всех атак с символическими ссылками и изменением файловой системы.
- Для операций с привилегиями нужна проверка модели угроз и корректные системные API.

## Практика

- Напиши индексатор каталога: имя, расширение, размер.
- Добавь фильтрацию по расширению и минимальному размеру.
- Обработай отсутствие прав доступа и удалённый во время обхода файл.
