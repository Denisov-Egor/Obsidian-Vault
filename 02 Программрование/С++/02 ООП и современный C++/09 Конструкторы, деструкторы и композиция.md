# 09 Конструкторы, деструкторы и композиция

## Цели
- [ ] Проектировать публичный интерфейс.
- [ ] Сохранять инварианты объекта.

## Теория
- Конструктор вызывается при создании объекта
- список инициализации инициализирует поля до тела. Порядок определяется порядком объявления полей. `explicit` запрещает нежелательные неявные преобразования. Деструктор завершает время жизни и освобождает принадлежащие ресурсы. Композиция — объект содержит другие объекты. Поля создаются в порядке объявления и уничтожаются в обратном.

## Типичные ошибки
- Ожидать порядок из списка инициализации
- вручную освобождать ресурс, которым уже управляет RAII
- бросать исключение из деструктора.
