# 11 Наследование и полиморфизм

## Цели
- [ ] Проектировать публичный интерфейс.
- [ ] Сохранять инварианты объекта.

## Теория
- Наследование задаёт отношение «является». `virtual` включает динамическую диспетчеризацию, `override` проверяет переопределение. Абстрактный класс имеет чисто виртуальную функцию. При удалении через базовый указатель нужен виртуальный деструктор. Срезка возникает при копировании производного объекта в базовый по значению. Композиция часто лучше наследования.

## Типичные ошибки
- Наследование только ради повторного использования
- нет виртуального деструктора
- несовпадающая сигнатура
- срезка объекта.
