# Версии стандарта C++

## Принцип

Стандарт языка и поддержка компилятора/стандартной библиотеки — разные вещи. Флаг `-std=c++20` выбирает режим языка, но конкретная библиотечная функция может быть реализована не полностью.

Перед использованием функции проверяй:
- версию стандарта, в которой она появилась;
- поддержку конкретной версией GCC/Clang и стандартной библиотеки;
- требования проекта и целевой среды.

## C++17

- structured bindings: `auto [key, value] = pair;`
- `if constexpr` для ветвления при компиляции шаблона;
- `std::optional`, `std::variant`, `std::any`;
- `std::string_view`;
- `std::filesystem`;
- `std::byte`;
- fold expressions для variadic templates;
- inline variables;
- `[[nodiscard]]`, `[[maybe_unused]]`, `[[fallthrough]]`.

## C++20

- concepts и `requires`;
- ranges и views;
- coroutines как языковой механизм;
- `std::span`;
- `std::jthread`, `std::stop_token`;
- календарные и часовые типы в `std::chrono`;
- `consteval`, `constinit`;
- three-way comparison `<=>`;
- designated initializers для агрегатов с ограничениями C++;
- `std::format` — поддержка зависит от реализации библиотеки.

## C++23

- `std::expected` для результата, который может содержать значение или ошибку;
- `std::print`/`std::println` при поддержке реализации;
- `std::mdspan`;
- `std::stacktrace` при поддержке;
- улучшения ranges и стандартной библиотеки.

## Как выбирать стандарт

- Для нового проекта выбери поддерживаемый стандарт и зафиксируй его в CMake.
- Не используй новейшую возможность только потому, что она существует.
- Для системного ПО учитывай версии ОС, компилятора, стандартной библиотеки и ABI.
- Не смешивай несколько способов решения одной задачи без причины.

## Практика

- Для `optional`, `string_view`, `span`, concepts и `expected` укажи версию стандарта.
- Проверь доступность функции в установленном компиляторе.
- Зафиксируй стандарт через `target_compile_features(target PRIVATE cxx_std_20)` в CMake.
