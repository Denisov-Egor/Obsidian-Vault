# 18 Обработка ошибок

## Цели
- [ ] Передавать ошибки предсказуемо.
- [ ] Сохранять корректность состояния.

## Теория
- Коды возврата подходят простым операциям. Исключения: `throw`, `try/catch`. No-throw guarantee — операция не бросает
- strong guarantee — при ошибке состояние не меняется
- basic guarantee — инварианты сохраняются. RAII освобождает ресурсы при раскрутке стека. Ошибки должны иметь понятный контракт и диагностический контекст.

## Типичные ошибки
- Пустой catch
- исключения для обычного ветвления
- частично изменённое состояние
- потеря первопричины.

- [ ] перевод между счетами атомарен на уровне бизнес-логики
- [ ] контракт ошибок хранилища.
