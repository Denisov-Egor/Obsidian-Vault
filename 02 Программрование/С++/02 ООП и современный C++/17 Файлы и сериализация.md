# 17 Файлы и сериализация

## Цели
- [ ] Обрабатывать ошибки ввода/вывода.
- [ ] Создать устойчивый формат данных.

## Теория
- `ifstream` читает, `ofstream` пишет, `fstream` поддерживает оба направления. Проверять открытие и результат операций
- `eof()` не использовать как единственную проверку цикла. Сериализация преобразует состояние в устойчивый формат. Текстовый формат требует экранирования разделителей
- бинарный — контроля версии и размеров. Не сохранять сырые указатели. Для важных данных полезна запись во временный файл с последующей заменой.

## Типичные ошибки
- Игнорировать ошибку записи
- не экранировать разделители
- сохранять адреса
- повредить основной файл при частичной записи.
