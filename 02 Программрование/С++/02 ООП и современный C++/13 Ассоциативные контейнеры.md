# 13 Ассоциативные контейнеры

## Цели
- [ ] Выбирать подходящий контейнер или алгоритм.
- [ ] Понимать сложность и ограничения.

## Теория
- `map` и `set` хранят упорядоченные ключи, основные операции O(log n). `unordered_map` и `unordered_set` используют хеширование: средняя сложность O(1), худшая O(n). `map[key]` создаёт значение при отсутствии ключа
- для чтения без вставки использовать `find`, `contains` или `at`. Хеш-коллизии возможны.

## Типичные ошибки
- Ожидать порядок у unordered-контейнера
- случайно создавать ключ при чтении
- считать среднюю O(1) гарантией.
