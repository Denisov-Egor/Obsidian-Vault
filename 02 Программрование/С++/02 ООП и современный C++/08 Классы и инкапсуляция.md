# 08 Классы и инкапсуляция

## Цели
- [ ] Проектировать публичный интерфейс.
- [ ] Сохранять инварианты объекта.

## Теория
- `class` объединяет поля и методы
- в `class` доступ по умолчанию `private`, в `struct` — `public`. `public` задаёт API, `private` скрывает состояние, `protected` полезен при наследовании. Инкапсуляция не даёт внешнему коду нарушать инварианты. Методы — функции-члены
- `this` указывает на текущий объект. Геттеры/сеттеры нужны по смыслу, а не автоматически. Метод чтения обычно помечается `const`.

## Типичные ошибки
- Открытые поля обходят правила класса
- сеттер допускает недопустимое состояние
- метод чтения не `const`
- одно состояние дублируется в нескольких полях.
