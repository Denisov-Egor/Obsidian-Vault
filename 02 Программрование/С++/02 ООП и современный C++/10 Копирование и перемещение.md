# 10 Копирование и перемещение

## Цели
- [ ] Проектировать публичный интерфейс.
- [ ] Сохранять инварианты объекта.

## Теория
- Copy constructor создаёт объект из другого
- copy assignment заменяет состояние существующего. Поверхностная копия копирует адрес, глубокая создаёт независимый ресурс. Move-операции передают ресурс
- `std::move` сам по себе ничего не перемещает. Rule of 0: предпочитать поля, которые сами управляют ресурсами. Rule of 3/5 важны для классов, вручную управляющих ресурсом.

## Типичные ошибки
- Два владельца одного сырого адреса
- утечка при присваивании
- некорректное самоприсваивание
- считать источник после move уничтоженным.
