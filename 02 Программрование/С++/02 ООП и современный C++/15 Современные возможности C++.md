# 15 Современные возможности C++

## Цели
- [ ] Использовать современные типы и конструкции безопасно.
- [ ] Понимать время жизни и владение.

## Теория
- `auto` выводит статический тип. `constexpr` допускает вычисление на этапе компиляции. `optional<T>` хранит значение или его отсутствие. `variant<T...>` хранит одну из альтернатив. Structured bindings разбирают пары/агрегаты. `string_view` — невладеющее представление строки и не продлевает её жизнь. Стандарт C++ должен быть явно задан в сборке.

## Типичные ошибки
- Считать auto динамической типизацией
- использовать пустой optional
- хранить string_view на уничтоженную строку
- не обработать альтернативы variant.

## Практика
- [ ] Необязательные поля конфигурации
- [ ] результат команды через variant
- [ ] парсер строк без копий при доказанном времени жизни.
