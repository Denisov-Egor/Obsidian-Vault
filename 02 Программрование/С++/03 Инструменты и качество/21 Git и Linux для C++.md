# 21 Git и Linux для C++

## Цели
- [ ] Собирать и сопровождать проект воспроизводимо.
- [ ] Пользоваться инструментами разработки.

## Теория
- Git фиксирует историю через коммиты
- изменения проходят рабочее дерево и индекс. Ветки изолируют работу. Linux CLI: навигация, поиск, права, процессы, перенаправления. Собирать с явным стандартом и предупреждениями. Процесс имеет PID, окружение и открытые дескрипторы.

## Типичные ошибки
- Коммитить артефакты и секреты
- большие несвязанные коммиты
- применять sudo без понимания.

## Практика
- [ ] Репозиторий с понятной историей
- [ ] сборка из чистой копии
- [ ] скрипт запуска и проверки.
