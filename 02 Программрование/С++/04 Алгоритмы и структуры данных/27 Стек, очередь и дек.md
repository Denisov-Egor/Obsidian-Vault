# 27 Стек, очередь и дек

## Цели
- [ ] Выбирать алгоритм по ограничениям задачи.
- [ ] Объяснять корректность и сложность.

## Теория
- Стек LIFO
- очередь FIFO
- deque поддерживает операции с обоих концов
- priority_queue извлекает элемент по приоритету. Применения: стек для скобок/DFS, очередь для BFS, приоритетная очередь для планировщика. Проверять пустое состояние перед доступом.

## Типичные ошибки
- Доступ к пустому контейнеру
- путаница FIFO/LIFO
- неверный порядок приоритетов.
