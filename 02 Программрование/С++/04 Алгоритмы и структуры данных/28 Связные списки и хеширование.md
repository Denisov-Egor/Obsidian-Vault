# 28 Связные списки и хеширование

## Цели
- [ ] Выбирать алгоритм по ограничениям задачи.
- [ ] Объяснять корректность и сложность.

## Теория
- Односвязный узел хранит следующий
- двусвязный — предыдущий и следующий. Вставка у известного узла может быть O(1), поиск O(n), локальность хуже массива. Хеш-функция преобразует ключ
- коллизии неизбежны. Хеш-таблицы дают среднюю O(1), худшую O(n). Чаще vector эффективнее list, если нет особой причины.

## Типичные ошибки
- Потеря остатка списка
- утечки
- считать хеш уникальным
- использовать list без необходимости.
