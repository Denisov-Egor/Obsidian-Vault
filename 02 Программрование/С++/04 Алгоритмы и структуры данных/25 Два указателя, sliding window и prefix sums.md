# 25 Два указателя, sliding window и prefix sums

## Цели
- [ ] Выбирать алгоритм по ограничениям задачи.
- [ ] Объяснять корректность и сложность.

## Теория
- Два указателя могут сократить O(n²) до O(n). Sliding window поддерживает состояние текущего окна. Префиксные суммы позволяют получать сумму диапазона за O(1) после O(n) подготовки. Простое монотонное окно суммы обычно требует неотрицательных элементов. Границы диапазона нужно определить явно.

## Типичные ошибки
- Sliding window при отрицательных числах без доказательства
- путаница включительных границ
- переполнение суммы
- неверное обновление окна.

## Практика
- [ ] Диапазон с заданной суммой
- [ ] много запросов суммы
- [ ] самый длинный участок с ограничением на число уникальных значений.
