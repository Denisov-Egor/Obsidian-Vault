# 30 Графы

- [ ] Выбирать алгоритм по ограничениям задачи.

## Теория
- Граф состоит из вершин и рёбер. Список смежности удобен для разреженных графов
- матрица требует O(V²) памяти. BFS находит кратчайший путь в невзвешенном графе
- DFS применяется для достижимости, компонент и циклов. visited предотвращает повторные обходы. Дейкстра — для неотрицательных весов.

## Типичные ошибки
- Не отмечать посещённые вершины
- BFS на произвольных весах
- ошибка индексации
- не обработать несвязный граф.
