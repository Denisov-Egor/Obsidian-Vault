# Log Analyzer

## Цель
Linux-утилита для потокового анализа больших лог-файлов.

## Требования
- [ ] Путь и параметры задаются аргументами командной строки.
- [ ] Файл читается потоково, без загрузки целиком в память.
- [ ] Считать строки и уровни `INFO`, `WARN`, `ERROR`.
- [ ] Выводить отчёт в терминал и файл.
- [ ] Разные коды завершения для успеха, аргументов и ошибок файла.
- [ ] Обрабатывать пустые, повреждённые и большие файлы.
- [ ] Unit-тесты парсера и статистики.
- [ ] CMake, README и примеры.

## Этапы
1. Парсер строки и статистика.
2. Потоковое чтение и отчёт.
3. Контракт ошибок и тесты.
4. Профилирование на больших файлах.
5. POSIX-ввод/вывод отдельной версией.
6. Параллелизм только после измерения узкого места.

## Готовность
- [ ] Работает на файлах разного размера.
- [ ] Ошибки пути, чтения и формата диагностируются.
- [ ] Тесты воспроизводимы.
- [ ] Производительность измерена на фиксированном наборе файлов.
